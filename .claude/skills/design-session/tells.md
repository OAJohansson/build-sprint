# AI design tells

Patterns models overuse until they read as "made by AI". None is wrong on its own: find each one
on the screen, try the alternative, and keep whichever the owner prefers. Our own list (the
article's was an image); add to it whenever we spot a new one.

## Colour and surface

| Tell | Try instead |
| --- | --- |
| Purple-to-blue gradients, gradient text | One flat accent from the product's own world |
| Glows, neon outlines, coloured shadows | No glow; separation by space or a hairline |
| Glassmorphism (blurred translucent panels) everywhere | Solid surfaces; blur only where content truly scrolls under |
| Every surface a card with a shadow | Content straight on the background; group by space |
| Cards inside cards | One level of container, or none |

## Layout

| Tell | Try instead |
| --- | --- |
| Centred hero, headline, subtitle, two buttons | Lead with the content itself (the shelf, the book) |
| Everything in a symmetric 3-column grid | A layout driven by the content's real shape and rhythm |
| A small label above every heading ("eyebrow") | Drop it; the heading says enough |
| Pills and badges on everything | Plain text, or one badge where it really matters |
| Icon in a tinted rounded square before every item | No icon, or a plain glyph only where it helps find things |

## Type

| Tell | Try instead |
| --- | --- |
| Inter or system sans for everything, all medium weight | A typeface with character for the voice moments; real weight contrast |
| Random words highlighted in colour or bold | Let hierarchy come from size, weight and position |
| Title Case On Every Label | Sentence case |

## Motion and decoration

| Tell | Try instead |
| --- | --- |
| Fade-and-slide-up on everything as it scrolls in | Motion only where it explains a change (decision 0007) |
| Sparkles for anything "smart" | Say what it does in plain words, or show the result |
| Emoji as icons | Real icons, or none |
| Abstract blobs and floating shapes as decoration | Real content, a real image, or empty space |

## Copy

| Tell | Try instead |
| --- | --- |
| "Unlock", "elevate", "seamless", "effortless", "journey" | The plain verb for what happens |
| Groups of three ("fast, simple and beautiful") | One concrete claim |
| A subtitle that restates the title | Cut it |
| Long helper text under every field | One hint where people actually get stuck |
| Exclamation marks and cheer in empty states | Calm and specific: what's missing and the one action |
