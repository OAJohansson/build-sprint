# X1 sections vs reference, 25 Oct 2026 (data-evals)

Eval X1: "map sections within 4 bars of the reference sections". Graded against the references and
the rule frozen in `2026-10-25-section-references.md`, before any map was seen. Nothing in that file
was changed.

**Result: X1 fails, 0 of 5 counted tracks pass (bar: 4 of 5).** The boundaries the map does find
are very precise (all within 1.0 s of the reference, most within 0.1 s, far inside the 4-bar
tolerance). It finds too few of them: 21 of 39 reference boundaries (54%) against the 75% needed
per track. Extras are low (5 in total; 4 of 5 tracks have ≤ 2). So the engine **under-segments**:
it misses build ↔ drop steps (4 of 5 tracks) and the late drop → cooldown → outro steps, and merges long
stretches into one section.

## Run

  sandbox env (`ACCESS_CODE=test-code`, Supabase and Anthropic keys empty, so nothing was saved to
  real data).
- Chrome 155, headful, own profile, tab capture auto-accepted for "Six AM Map", tab not muted.
  Driven by `apps/07-six-am/scripts/map-drive.mjs` (`/map?url=…&auto=1`), one track at a time.
- Each map took about the track's length (e.g. Cola: 416.8 s listen, 49 ms build), coverage 100% on

- Scoring script: one-to-one, closest-first matching within 960 / BPM s, label changes only,
  optional (same-label) reference splits and the track start/end not scored. Version check: every
  analysed length is within 1.5 s of the annotated one, so all five count.

## Patterns (for the engineer, not fixes)

1. **Build and drop are merged** on four of five: B2 0:44, B3 0:31 and 4:09, B4 2:04, B5 0:27 and
   1:22 are missed. Where the engine sees one step, it is often at the build and labelled drop
   (B1 0:31 and 1:50, B3 1:02, B5 0:55, 16 bars before the reference drop).
2. **The tail is under-split:** drop → cooldown (B1, B2, B3, B4) and cooldown → outro (B2, B3) are
   missed. B2 has no outro at all.
3. **Long one-label sections** hide repeated drop/breakdown swaps (B1 3:24–6:17, 88 bars).
4. **Precision is not the problem:** matched boundaries are within ±1.0 s, and 4 of 5 tracks are
   within the extras limit. A small, consistent offset (B2 +1.0 s, B4 +0.5 s) comes from the
   downbeat origin and is well inside tolerance.
