headless Chromium. Tab capture can't be clicked headlessly: one run used a stubbed capture (a
sawtooth) with the real widget, S2/S4 were partly judged from `?demo=1`. Genre accuracy is not
judged here (that's data-evals on the owner's real runs).

## Trust check (no audio)

Storage held only `six-am:ears-source/queue/results` (≤ 1.5 kB of text) and the Cache Storage
model `ears-models-v1`; IndexedDB and OPFS empty. The only non-GET requests were SoundCloud widget
telemetry (≤ 7 kB), none from Six AM. No `MediaRecorder` in the code; the only Blob is the CSV/JSON
export. Nothing on screen says record or save audio.

## Value

Earns its place: the % styles with "differs", Copy for Claude, the queue. Missing that would bring
them back: marking a track as filed and a "31 / 56 placed" progress line (→ backlog).
