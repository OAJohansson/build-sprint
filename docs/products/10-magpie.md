## Learned

- Design before code paid off: features agreed first, then 10 directions, a round where only the mascot's moments were drawn, and one final flow; the build matched it and the critic ended at 9/10.
- A mascot with a job carries the brand: Maggie "collects shiny things", so every screen had a line and a moment to give her.
- When a model won't keep a rule (the sticker outline), draw that part in code around it; and open the deployed preview, not just the local build (a native module crashed only on Vercel).
